
# C++ DSA Visualizer

A menu-driven Data Structures and Algorithms project built using C++17.

## Features

### Sorting Algorithms
- Bubble Sort
- Selection Sort
- Insertion Sort
- Merge Sort
- Quick Sort

### Searching Algorithms
- Linear Search
- Binary Search

### Data Structures
- Stack (LIFO)
- Queue (FIFO)
- Singly Linked List

## Technologies Used
- C++
- C++ Standard Template Library (STL)
- Object-Oriented Programming
- Data Structures and Algorithms

## How to Run

Compile the source code:

```bash
g++ -std=c++17 -Wall -Wextra -pedantic main.cpp -o dsa
```

Run on Windows:

```bash
.\dsa.exe
```

Run on Linux or macOS:

```bash
./dsa
```

## Learning Outcomes
- Understand sorting and searching algorithms.
- Explore stack and queue operations.
- Practice linked list implementation and memory management.
- Compare algorithm time complexities.
