# 💰 Expense Tracker in C++

A console-based personal expense tracker built with C++17.
Track expenses, organize spending, and generate monthly summaries.

## ✨ Features

- Add and delete expenses
- View all recorded expenses
- Search by category or description
- Monthly spending summaries
- Input validation
- Persistent CSV file storage
- No external libraries required

## 🛠️ Built With

- C++17
- Object-oriented programming
- STL vectors and algorithms
- File handling
- CSV data storage

## 🚀 Getting Started

### Prerequisites

Install a C++17-compatible compiler, such as GCC or Clang.

### Compile

```bash
g++ -std=c++17 -Wall -Wextra -pedantic main.cpp -o expense-tracker
```

### Run

Linux/macOS:

```bash
./expense-tracker
```

Windows:

```powershell
.\expense-tracker.exe
```

## 📂 Data Storage

The program creates `expenses.csv` in its working directory.
Back up this file to preserve your expense records.
